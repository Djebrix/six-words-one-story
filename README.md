A complete story in exactly six words. See the competition at https://make.fun/bounty/u-deranalabs-six-words-one-story-f982e410.

## Run

```sh
python3 main.py
```

This writes the six-word story to `entry.txt` inside `$ENTRY_OUTPUT_DIR` (default `/output`). Standard library only, no network, deterministic.
